Frequently Asked Questions

Can I continue driving my Honda Accord with code P0304?

If the check engine light is solid without loud engine knocking or violent shaking, you can typically drive short distances to a repair shop. However, if the light is flashing or the engine is shuddering, pull over immediately; raw fuel entering the exhaust will melt your catalytic converter ($1,200+ repair).

Will clearing the code with an OBD scanner fix the problem?

No. Clearing the code merely resets the dashboard light. Once the engine control module (ECM) completes its diagnostic drive cycle, it will re-detect the underlying fault condition and illuminate the MIL light again.
